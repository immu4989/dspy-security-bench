# v0.8.0 — Bring Your Own Agent

DSPy Security Bench can now connect a real agent repository to the same
framework-neutral security contract in one command.

## Highlights

- Native bridges for OpenAI Agents SDK, LangChain/LangGraph, Pydantic AI,
  CrewAI, and Microsoft AutoGen AgentChat.
- An explicit callback bridge for MCP clients and custom agent loops.
- `dspy-security-bench integrate` detects direct dependencies and generates a
  reviewable adapter, contract test, integration manifest, and manually
  triggered ProofRun workflow.
- `dspy-security-bench doctor` checks imports, fresh-agent isolation,
  immutable engine pinning, workflow wiring, attestation permissions, and
  credential readiness without invoking `agent.run`; factories are expected to
  be side-effect free.
- A weekly zero-provider-call compatibility matrix detects upstream SDK drift.
- CrewAI's current Python 3.10–3.13 dependency boundary is encoded explicitly;
  the base package and other bridges retain Python 3.14 support.
- ProofRun can import a generated top-level target from the evaluated
  repository while preserving clean-job evidence recomputation.
- The interactive dashboard now includes a responsive framework onboarding
  experience with a clear no-surprise-spend policy.

## Start here

```bash
pip install "dspy-security-bench[openai-agents]"
dspy-security-bench integrate
dspy-security-bench doctor
```

See the [integration guide](../integrations.md) for every supported framework,
generated-file contract, custom callback API, and CI safety defaults.

## Trust boundary

The adapters translate an SDK's tool interface into the benchmark contract;
they do not claim to certify the model, provider, framework, or deployment.
Generated workflows start with `workflow_dispatch` so adoption does not create
unexpected model charges.
