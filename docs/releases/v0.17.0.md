# v0.17.0 — Runtime evidence and authorization-race assurance

v0.17.0 moves the Mission Assurance Commons from synthetic twins toward
operator-owned runtime evidence, while adding bounded exhaustive exploration of
the authorization schedules an agent architecture permits.

## Highlights

- **ScheduleProof v1** counts every reachable topological ordering of a strict
  data-only event graph, explores up to 100,000 schedules, checks eight
  authority, approval, token, scope, identity, audience, effect, and receipt
  invariants, and returns minimal causal counterexamples.
- ScheduleProof distinguishes `bounded_safe`, `unsafe`, and
  `incomplete_review`. Its unsafe-schedule fraction is explicitly a
  schedule-space ratio—not a production probability.
- Strict scenario and report schemas, offline semantic recomputation,
  content-addressed protocol/scenario identity, SARIF 2.1.0, CI completeness
  gates, ContinuousProof baselines, and four fictional starter profiles ship in
  the wheel.
- The **TraceProof Runtime Kit** records content-free tool-boundary metadata for
  OpenAI Agents, LangChain/LangGraph, Pydantic AI, CrewAI, AutoGen, DSPy, MCP,
  and custom loops. Its doctor inspects manifests without importing or running
  the target.
- Stable MCP 2025-11-25 evidence probes preserve `pass`, `fail`,
  `not_observed`, and `not_applicable` rather than turning missing evidence into
  success.
- A deterministic 20-case sanitizer challenge, secret-shaped value detection,
  bounded OTLP JSON Lines import, and a reproducible fictional OPA plus
  OpenTelemetry Collector lab strengthen TraceProof's privacy boundary.
- The public TraceProof registry admits only sanitized, recomputable community
  bundles. The dashboard adds a responsive ScheduleProof race explorer and
  TraceProof evidence ledger.

## Install

```bash
pip install dspy-security-bench==0.17.0

dspy-security-bench schedule demo
dspy-security-bench schedule init \
  --profile revocation-race --out scheduleproof.json
dspy-security-bench schedule run scheduleproof.json \
  --json-out artifacts/scheduleproof.json \
  --sarif-out artifacts/scheduleproof.sarif \
  --fail-on-unsafe --require-complete

dspy-security-bench trace runtime doctor --root .
dspy-security-bench trace challenge --out artifacts/redaction-challenge.json
```

## Evidence boundary

ScheduleProof proves only the result of the declared bounded atomic-event model;
it cannot discover omitted events or establish a production scheduler
distribution. TraceProof proves properties of the supplied sanitized bytes; it
cannot establish trace completeness. Pseudonymization is not anonymization.

All built-in profiles, missions, principals, approvals, resources, costs, and
effects are fictional scorer or schema fixtures. Results are not model
certifications, government-authored requirements, compliance determinations,
risk acceptances, procurement decisions, government endorsements, or
authorizations to operate.
