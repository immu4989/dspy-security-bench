# v0.16.0 — TraceProof operational assurance lab

v0.16.0 connects privacy-bounded operational telemetry to deterministic agent
security findings, temporal authorization tests, signed community protocols,
and owner-measured mission economics.

## Highlights

- **TraceProof** sanitizes local OTLP JSON, applies 12 deterministic rules, and
  exports content-addressed JSON, SARIF, OSCAL 1.2.2, and synthetic replay twins.
- **AgentGraphTwin v2** adds temporal ordering, parallel approval races,
  revocation latency, audience exchange, and multi-effect boundaries.
- **Live AuthorityBridge** exercises an operator-declared backend command using
  canonical stdin/stdout JSON while withholding credentials and command text
  from the self-attested report.
- **Signed MissionPack Commons** adds Ed25519 envelopes, local catalogs, and
  five explicitly synthetic public-service MissionPack examples.
- **ValueProof** recomputes owner-supplied mission, safety, cost, latency, human
  review, recovery, and portability observations without ranking candidates.
- **ContinuousProof** accepts TraceProof, AgentGraphTwin v2, and ValueProof as
  drift evidence.
- The interactive dashboard now presents a responsive TraceProof flight
  recorder and the expanded Mission Assurance Commons workflow.

## Install

```bash
pip install dspy-security-bench==0.16.0
pip install "dspy-security-bench[signing]==0.16.0"  # MissionPack signatures
dspy-security-bench trace demo --out-dir artifacts/traceproof
```

All packaged demos and built-in mission packs are synthetic scorer or schema
fixtures. They are not model measurements, government-authored requirements,
product certifications, compliance determinations, or authorizations to
operate.
