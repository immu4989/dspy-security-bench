# v0.12.0 — mission assurance evidence

This release introduces two connected capabilities:

1. **IncidentTwin** measures functional cyber-response side effects across five
   frozen clean/poisoned counterfactual pairs in a fully synthetic environment.
2. **FederalProof** turns verified repeated evidence into OSCAL 1.2.2
   assessment inputs, a conditional POA&M, an impact-assessment annex, and a
   QASP scorecard bound by a content-addressed manifest.

Neither capability is a model leaderboard claim, operational response guide,
compliance determination, government endorsement, procurement decision, or
authorization to operate.

## Try the offline laboratory

```bash
pip install --upgrade dspy-security-bench
dspy-security-bench incident demo
dspy-security-bench federal init
```

## Attested IncidentTwin workflow

```yaml
permissions:
  contents: read
  id-token: write
  attestations: write

jobs:
  incident-proof:
    uses: immu4989/dspy-security-bench/.github/workflows/proofrun.yml@v0.12.0
    with:
      evidence-kind: incident
      agent: myapp.security:build_agent
      trials: 10
      min-lower-bound: 0.80
```

The evaluation job is treated as untrusted. A clean job installs the immutable
v0.12.0 verifier, recomputes the complete nested evidence, and only then attests
the exact JSON. The statistical gate runs after preservation and attestation.

Valid IncidentTwin bundles can be contributed under `submissions/incident/`.
Admission is score-neutral: CI recomputes the complete nested evidence offline,
and the public dashboard derives provenance tiers only from reviewed digest
registries.
