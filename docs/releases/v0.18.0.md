# v0.18.0 — Structural causality for agent authorization

v0.18.0 connects privacy-bounded runtime structure to exhaustive authorization-
race analysis. CausalProof keeps observed runtime parentage, explicit system-
owner guarantees, generic span links, and wall-clock hints in separate
provenance classes before generating a ScheduleProof scenario.

## Highlights

- **CausalProof v1** reads only trace/span IDs, parent IDs, links, timestamps,
  and dropped-record counters from supplied OpenTelemetry bytes. Span names,
  attributes, events, status, resource/scope data, prompts, arguments, results,
  and credentials are never read.
- Only observed parent edges and bounded owner assertions enter ScheduleProof.
  Generic links remain undirected and timestamps remain non-proving review
  hints, consistent with the OpenTelemetry trace and file-export contracts.
- Missing or unbound spans, duplicate identities, dropped records, and invalid
  combined graphs produce stable diagnostics and `review_required` rather than
  an optimistic safety result.
- Strict manifest, report, and community-submission schemas; canonical digests;
  offline semantic recomputation; end-to-end ScheduleProof gates; and a public
  evidence registry ship in the wheel.
- A native **OpenAI Agents SDK `TracingProcessor`** reads five structural span
  lifecycle fields while ignoring SDK span payloads, errors, trace metadata,
  prompts, responses, and tool I/O.
- A native **LangGraph `BaseCallbackHandler`** binds selected graph nodes while
  discarding graph state, inputs, outputs, messages, errors, and tool data. Its
  compiled graph guarantees remain explicitly asserted rather than being
  relabeled as observations.
- Review-first scaffolds, real-SDK zero-provider-call compatibility tests,
  deterministic native-ID pseudonymization, loop-aware event factories, runtime
  documentation, contribution intake, and responsive dashboard cards make the
  integration usable beyond the fictional reference fixture.

## Install

```bash
pip install dspy-security-bench==0.18.0

dspy-security-bench causal demo --out-dir artifacts/causalproof
dspy-security-bench causal integrations
dspy-security-bench causal scaffold openai-agents --out causal_openai.py
dspy-security-bench causal scaffold langgraph --out causal_langgraph.py
```

For both optional SDKs:

```bash
pip install "dspy-security-bench[openai-agents,langchain]==0.18.0"
```

## Evidence boundary

CausalProof verifies how the supplied structural bytes and owner assertions
were converted. It cannot establish trace completeness, sampling coverage,
clock synchronization, deployed-code conformance, production incident
likelihood, or the truth of an owner assertion. Native identifier
pseudonymization is not anonymization, and manifest event metadata requires
local owner review.

The generated results are evaluation evidence, not certifications, compliance
determinations, government-authored requirements, risk acceptances,
procurement decisions, government endorsements, or authorizations to operate.
