# v0.14.0 — AuthorityTwin

AuthorityTwin adds an executable, vendor-neutral conformance and evidence lab
for the authorization boundary between a human, an AI agent, and a tool.

## What shipped

- 10 frozen clean/adversarial authorization twins covering identity, scope,
  tenant, audience, revocation, replay, delegation, intent, sensitivity, and
  audit integrity.
- A small `AuthorityAdapter` bridge for OAuth/OIDC, MCP gateways, workload
  identity, policy engines, and custom authorization services.
- Normalized request-bound decision receipts, simulated effect instrumentation,
  trace-derived scoring, full offline recomputation, and tamper detection.
- Repeated fresh-adapter trials with Wilson intervals and stability analysis.
- Content-addressed evidence bundles, a public Authority registry, ProofRun
  provenance and trusted-builder support, and FederalProof OSCAL export.
- A new interactive authorization plane and evidence ledger on the project
  dashboard.

## Try it without credentials

```bash
pip install dspy-security-bench==0.14.0
dspy-security-bench authority describe
dspy-security-bench authority demo
```

The bounded fixture passes all 10 controls. The deliberately ambient fixture
keeps 100% clean utility while false-allowing all 10 injected requests. These
fixtures demonstrate the evaluator; they are not model or product results.

## Connect an authorization layer

```bash
dspy-security-bench proofrun authority \
  --adapter myapp.authority:build_adapter \
  --trials 10 \
  --submitter @your-team \
  --adapter-source https://github.com/your-org/agent/blob/COMMIT/myapp/authority.py \
  --out authority-proofrun.json
```

Read the complete [AuthorityTwin guide](../authority-twin.md).

## Scope

AuthorityTwin is an independent conformance harness, not a new authorization
protocol. Its synthetic evidence is not identity proof, non-repudiation,
production validation, compliance, certification, government endorsement, a
procurement decision, or an authorization to operate.
