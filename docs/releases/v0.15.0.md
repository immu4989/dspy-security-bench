# v0.15.0 — Mission Assurance Commons

v0.15.0 connects mission scoping, multi-agent authorization, evidence drift,
and acquisition review into one open, locally runnable workflow.

## Highlights

- **InventoryForge:** bounded public-inventory normalization with contact-field
  removal and human-review-required synthetic MissionPack drafts.
- **AgentGraphTwin:** six clean/adversarial authorization paths with exact path
  identity, normalized receipts, first unsafe edge, and synthetic blast radius.
- **AuthorityBridge:** translation contracts and deny-by-default starters for
  OPA, Cedar, OpenFGA, OAuth-bound MCP tools, and SPIFFE.
- **ContinuousProof:** tamper-evident evidence baselines and owner-threshold
  regression comparison.
- **AcquisitionProof:** content-addressed vendor-neutral test plans, QASP
  inputs, portability checks, cost fields, and reevaluation triggers.
- **Dashboard:** a new responsive Mission Assurance Commons workflow and
  multi-agent authorization graph, plus a dedicated social preview card.
- Updated benchmark card, research paper draft, architecture, public-sector
  positioning, and end-to-end implementation documentation.

## Install

```bash
pip install dspy-security-bench==0.15.0
dspy-security-bench graph demo
dspy-security-bench authority bridge list
```

## Trust boundary

All new built-in cases are synthetic and perform no real external effects.
Generated mission packs require human review. Bridge fixtures validate
translation, not named products. ContinuousProof does not accept risk.
AcquisitionProof does not select or recommend a vendor. Nothing in this release
is certification, compliance, government endorsement, or an authorization to
operate.
