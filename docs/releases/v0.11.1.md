# v0.11.1 — verified card delivery

This patch keeps the v0.11.0 Open Control Evidence Registry feature intact and
fixes one trusted-builder artifact detail.

The reusable workflow now renders the SVG evidence card in the clean
verification job, after the JSON has passed complete offline recomputation. The
final workflow artifact therefore contains both:

- the exact JSON subject covered by GitHub/Sigstore attestation; and
- a card derived by the trusted engine from that verified JSON.

This is safer than transferring an SVG created in the credential-bearing,
untrusted evaluation job, and it matches the documented download experience.

```yaml
jobs:
  control-evidence:
    uses: immu4989/dspy-security-bench/.github/workflows/proofrun.yml@v0.11.1
    with:
      evidence-kind: control
      agent: myapp.security:build_agent
      policy: policies/production.yaml
      trials: 10
```

See the complete [v0.11.0 registry release notes](v0.11.0.md) and
[registry guide](../control-evidence-registry.md).
