# v0.11.0 — Open Control Evidence Registry

A policy file says what should happen. This release makes teams publish what
actually happened when the exact policy was turned on.

## Highlights

- New Open Control Evidence Registry for policy-bound, content-addressed,
  contribution-ready RepeatControlTwin experiments.
- New `proofrun control` path with separate containment, policy-on harm-free,
  clean-preservation, safe-resistance, and effect-stability gates.
- JSON and safe 1200×630 SVG evidence artifacts are written before gate
  enforcement, so weak and failed controls remain inspectable.
- `proofrun verify` automatically detects both agent-only and control-evidence
  bundles and recomputes the full evidence tree offline.
- Composite action and central reusable workflow support both experiment kinds;
  the latter separates credential-bearing evaluation from clean verification
  and attestation.
- Public contribution CI now validates `submissions/control/` alongside Impact
  submissions.
- The interactive site adds a highly visual public evidence ledger generated
  from committed bundles and separately reviewed attestation/reproduction
  registries.

## Why it matters

The registry admits valid negative results. Public comparison requires enough
trials, fresh case/condition isolation, zero runtime errors, redacted arguments,
and complete recomputability—not a favorable score. This gives government,
vendors, enterprises, researchers, and users a common artifact for reviewing
whether a guardrail contains harm, safely completes the mission, and preserves
clean work.

The evidence remains scoped to five fixed synthetic ProcureBench pairs. It is
not certification, predicted economic loss or benefit, or independent
observation of a hosted model provider.

## Try it

```bash
pip install dspy-security-bench==0.11.0

dspy-security-bench proofrun control \
  --agent myapp.security:build_agent \
  --policy policies/production.yaml \
  --policy-source "https://github.com/you/agent/blob/COMMIT/policies/production.yaml" \
  --trials 10 \
  --submitter "@your-handle" \
  --agent-source "https://github.com/you/agent/tree/COMMIT" \
  --out control-evidence.json \
  --card-out control-evidence.svg

dspy-security-bench proofrun verify control-evidence.json --offline
```
