# Support

- Usage questions and reproducible bugs: [GitHub Issues](https://github.com/immu4989/dspy-security-bench/issues)
- Design proposals: start with the relevant issue form before a large pull request.
- Sensitive vulnerabilities: follow [SECURITY.md](SECURITY.md); do not open a public issue.

Include the package version, Python version, operating system, exact command,
minimal configuration with secrets removed, and complete error text. Community
support is best effort; this project does not provide an SLA, legal advice,
compliance advice, procurement approval, or production incident response.
